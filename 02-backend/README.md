# 02. Backend — Серверный API и Авторизация

## Зона ответственности
Разработка серверного API, системы регистрации и аутентификации пользователей, бизнес-логики работы с новостями и интеграции с AI-сервисом.

---

## Основной функционал

### 1. Аутентификация и авторизация (Auth)
- Регистрация пользователя с хэшированием паролей (bcrypt / argon2).
- Вход в систему с генерацией JWT-токенов (Access & Refresh tokens).
- Middleware / Dependency для защиты приватных эндпоинтов (Protected Routes).
- Эндпоинты профиля текущего пользователя (`/api/auth/me`).

### 2. CRUD и работа с новостями
- Получение списка новостей с фильтрацией, пагинацией и поиском (`GET /api/news`).
- Получение детальной информации о новости с прикрепленными инсайтами (`GET /api/news/{id}`).
- Добавление/удаление новостей в избранное пользователя (`POST /api/news/{id}/favorite`).
- Эндпоинты для добавления новых событий (для парсера / администратора).

### 3. Интеграция с AI-сервисом
- Вызов сервиса нейросети (`03-ai-service`) при добавлении новой новости или по запросу пользователя.
- Кэширование сгенерированных инсайтов в базе данных, чтобы избежать повторных затратных обращений к LLM.
- Эндпоинт для генерации дополнительного инсайта или ответа на вопрос пользователя по новости.

---

## Базовые API-контракты

```text
POST /api/auth/register       -> Регистрация нового аккаунта
POST /api/auth/login          -> Вход, выдача JWT токена
GET  /api/auth/me             -> Данные текущего авторизованного пользователя

GET  /api/news                -> Список новостей с пагинацией и фильтрами
GET  /api/news/{id}           -> Детальная новость + AI-инсайт
POST /api/news/{id}/favorite  -> Добавить/удалить из закладок
POST /api/news/{id}/ask-ai    -> Задать вопрос нейросети по новости
```

---

## Рекомендуемый стек
- **Язык и фреймворк**: Python (FastAPI) или Node.js (Express / NestJS)
- **Аутентификация**: JWT (PyJWT / jsonwebtoken) + Passlib / Bcrypt
- **ORM / База данных**: SQLAlchemy / Prisma / Tortoise ORM
- **Документация**: Swagger / OpenAPI (автоматически в FastAPI)

---

## Взаимодействие с командой
- **Для Frontend (`01-frontend`)**: стабильные контракты API, документация Swagger (`/docs`), корректные CORS-заголовки.
- **С AI-модулем (`03-ai-service`)**: протокол обмена данными (внутренний HTTP API или модуль вызова).
- **С Infra (`04-infra-db`)**: подключение к БД по строке соединения из `.env`.
