# Передача команде · 26 октября 2026

## Что сделано

1. Подключён OpenAI-compatible шлюз организаторов. Точные адреса и модели сверены
   с [инструкцией](https://docs.google.com/document/d/1ly8GsI_-oPnCQWvtZ4nGevnnDP2MGYIfpn2zOUFxZ_4/edit).
   Gemma — планирование/классификация; Qwen3.6 — генерация и чат; GLM — самопроверка.
   Все 6 разрешённых ID доступны в настройках, посторонние отклоняются до запроса.
2. Для Qwen/GLM отключён reasoning по умолчанию. При включённом thinking реальный
   запрос обрывал JSON после 4000 токенов и достигал общего таймаута. После изменения
   один полный инсайт занял 19,5 с и прошёл самопроверку за одну попытку. Это единичное
   измерение, не гарантия задержки API.
3. В ленте краткий вывод до 210 символов и следующий шаг до 140. Нажатие
   «Подробный анализ» показывает все шесть разделов, источники и вложенные шаги.
4. Светлая палитра, красный акцент, локальный Golos Text, адаптивная сетка,
   поиск, темы, состояния загрузки/ошибок, восстановление сессии.
5. Docker передаёт актуальные настройки и согласованные таймауты. Pages собирается
   в явном демо-режиме: серверный ключ в браузере не нужен.
6. Восстановлены синтетические CSV-фикстуры и чтение профиля для существующих
   проверок DatasetStore. Тестовые CSV разрешены в Git, полные датасеты игнорируются.

## Запуск после git pull

```bash
git pull --ff-only origin main
cp .env.example .env  # только если .env ещё не создан; существующий не перезаписывать
# В локальном .env заполнить AI_LLM_API_KEY ключом команды.
docker compose up --build -d
docker compose ps
```

По умолчанию UI — `http://localhost:3000`, backend — `:8000`, AI — `:8001`.
Порты можно переопределить в `.env`; локальная проверка этого обновления использовала
3200 / 8200 / 8201. Вход: `alfa-hack-2026` / `password123`.

`/health` AI-сервиса показывает выбранный режим и модели; это конфигурация, а не
самостоятельная проверка доступности провайдера. Реальные запросы дополнительно
проверены генерацией инсайта и вопросом через backend.

Backend обогащает 27 комбинаций новость/компания/роль в фоне, по очереди. Первые
карточки сразу доступны с демо-текстом; нажмите «Обновить», чтобы увидеть готовые
результаты LLM. Прогресс доступен в `/health` backend, поле `enrichment`.

## Проверка

```bash
cd 01-frontend
npm ci
npm run lint
npm run build
cd ../02-backend
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
cd ../03-ai-service
uv sync --frozen
bash scripts/check.sh
```

Результаты этого обновления: 55 тестов backend и 126 тестов AI, Ruff, mypy,
ESLint и production-сборка. Браузерный сценарий: вход → краткая карточка → шесть
разделов анализа → избранное → чат → перезагрузка → смена роли/компании → поиск.
Ширины 320/390/768/1440 px проверены без горизонтального скролла в финальной сборке.

## Границы

Встроенные новости и профили — демо, даже если анализ сгенерирован настоящей LLM.
Поэтому `is_demo` может быть true одновременно с `insight.mode=llm`. Интерфейс
показывает «Вывод AI · демо-новость». Пользователи и избранное пока в памяти backend.
В локальной проверке корпус банковских PDF не подключён: позиция банка не выдумывается.
Полный поток живых новостей и интеграция постоянной БД остаются отдельными задачами.

Общий лимит командного ключа — 500 ₽/день; сброс в 03:00 МСК по инструкции.
Резервный base URL: `https://api.alfahack-gateway26.ru/v1`. Автоматического переключения
между адресами нет — при необходимости поменяйте `AI_LLM_BASE_URL` в окружении.
Ключ не включён в Git, примеры, логи проверки или фронтенд.
