# THIRD_PARTY_NOTICES

В данном документе перечислены сторонние компоненты, модели машинного обучения, библиотеки, датасеты и смоделированные интеграции, используемые в проекте **Alfa News Insights**.

---

## 1. Модели машинного обучения (LLM)
Используются строго в соответствии с Приложением 3 регламента кейса:
- **DeepSeek-V4.1-Flash** (DeepSeek AI) — анализ контекста, взаимосвязей и структурирование инсайтов.
- **Qwen3.6 35B A3B / Qwen3-VL-30B-A3B-Instruct** (Alibaba Cloud) — обработка текста, мультимодальный анализ таблиц и графиков.
- **GLM-5.3-Flash** (Zhipu AI) — углубленный логический анализ и оценка рисков.
- **Gemma 4 26B A4B** (Google) — быстрая классификация и извлечение сущностей.
- **Kimi-K2.6** (Moonshot AI) — суммаризация длинных аналитических отчетов.

## 2. Открытые библиотеки и фреймворки

### Frontend
- **React / Next.js** (MIT License) — UI-фреймворк.
- **Tailwind CSS** (MIT License) — утилитарные стили.
- **Lucide Icons** (ISC License) — набор векторных иконок.

### Backend
- **FastAPI** (MIT License) — веб-фреймворк для построения REST API.
- **Uvicorn** (BSD License) — ASGI веб-сервер.
- **Pydantic** (MIT License) — валидация данных и схем.

- **PyJWT / Passlib / Bcrypt** (MIT / BSD License) — хеширование паролей и JWT-авторизация.

### AI & Data (03-ai-service)
- **LangChain / LangGraph / langchain-openai** (MIT License) — граф агента и вызовы LLM через OpenAI-совместимый API.
- **FastAPI, Uvicorn, Pydantic, pydantic-settings** (MIT / BSD) — HTTP-сервис и схемы.
- **structlog** (MIT / Apache-2.0) — структурированные логи.
- **Qdrant Client** (Apache-2.0) — embedded-векторное хранилище для RAG.
- **FastEmbed** (Apache-2.0) и модели `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (Apache-2.0), `Qdrant/bm25` — эмбеддинги без torch (ONNX).
- **PyMuPDF** (AGPL-3.0; коммерческая лицензия у Artifex) — рендер страниц PDF для OCR.
- **pytesseract** (Apache-2.0) + **Tesseract OCR** (Apache-2.0, системный пакет) — распознавание сканов отчетов.
- **feedparser** (BSD-2-Clause), **httpx** (BSD-3-Clause) — загрузка и разбор RSS.
- **Pandas / NumPy** (BSD License) — обработка CSV-датасетов кейса.
- **PyYAML** (MIT) — каталог отчетов.
