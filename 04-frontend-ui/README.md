# 04. Frontend / UI — Интерфейс Альфа-Бизнеса и Интерактивная визуализация

## Зона ответственности
Создание премиального интерфейса в экосистеме «Альфа-Бизнес», где сложная графовая аналитика и мультиагентные рассуждения считываются руководителем компании за 10 секунд.

---

## Ключевые компоненты и сценарии

### 1. Главный экран и точка входа в «Альфа-Бизнес»
- **Виджет «Альфа-Пульс / Радар рисков и сделок»**:
  - Располагается на основном дашборде интернет-банка.
  - Показывает счетчик критических инсайтов и суммарный финансовый объем под риском / к захвату в рублях.
- **Быстрый переключатель роли ЛПР**:
  - `CEO / Собственник`: на первом плане «Перехват контрактов» (Фича №4) и динамика рынка.
  - `CFO / Казначей`: на первом плане «Детектор блефа поставщиков» (Фича №1), кассовые разрывы и ковенанты.
  - `Главный бухгалтер`: на первом плане «Детектор фантомного штата» (Фича №5), налоговые риски и субсидиарка (Фича №6).
- **Селектор демо-профилей**: быстрое переключение между 3–4 тестовыми компаниями.

### 2. «Сейсмограф Цепочки Поставок» (Фича №10)
- Интерактивный Canvas/SVG/WebGL граф:
  - Центральный узел: анализируемая компания.
  - Окружение: 1-й и 2-й круг контрагентов (поставщики, покупатели, бенефициары `SYNTHETIC_F`).
  - Визуализация «ударной волны» новости: уязвимые звенья подсвечиваются цветом с суммами под риском (`PAY_AMT`).
  - Фильтры по типу связи, объему оборота и статусу уязвимости.

### 3. Специализированные карточки киллер-фич
- **Карточка «Детектор блефа поставщика» (Фича №1)**:
  - Сравнительная шкала: «Запрошено поставщиком %» vs «Обоснованный потолок по данным Альфа-Банка %».
  - Выделенный счетчик экономии (например: *«Потенциальная экономия: 2 450 000 ₽»*).
  - Готовый проект аргументированного ответа контрагенту.
- **Карточка «Перехват контрактов» (Фича №4)**:
  - Список доступных объемов у целевых заказчиков региона.
  - Кнопка действия: *«Оформить предодобренную гарантию»* / *«Подключить факторинг»*.
  - Виджет «Индекс стадного иммунитета» (Фича №8): *«78% компаний вашей отрасли уже используют гарантии Альфа-Банка»*.

### 4. Панель трассируемости и блок «Адвокат Дьявола»
- **Цветовая разметка контента тремя бейджами**:
  - `Факт (Первоисточник)` — верифицированное внешнее событие.
  - `Позиция Альфа-Банка` — цитата с кликабельной ссылкой на PDF-отчет и номер страницы.
  - `Вывод ИИ-агента` — аналитика с указанием сработавших триггеров компании.
- **Блок «Адвокат Дьявола»**: интерактивный переключатель/блок со скептической оценкой («Контрфакты и сценарии, при которых прогноз не сбудется»).
- **Режим живого стриминга рассуждений**: визуализация цепочки рассуждений агента при клике на карточку.

### 5. Живая проверка произвольной новости (Демо-режим для жюри)
- Поле ввода текста / URL любой свежей новости.
- Запуск моментального скоринга и пересчета «Сейсмографа» в реальном времени.

### 6. Дизайн-система и стиль
- Строгий корпоративный минимализм экосистемы Альфа-Банка.
- Контрастная модульная сетка **Bento Grid**.
- Цветовая палитра: глубокий графитовый / чистый светлый фон, нейтральные разделители.
- Фирменный красный акцент `#EF3124` используется исключительно для критических рисков и главных кнопок (Call to Action).
