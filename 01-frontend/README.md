# 01. Frontend — Клиентская часть веб-приложения

## Зона ответственности
Разработка клиентского интерфейса в концепции **«Новость-Инсайт»**: каждый элемент ленты объединяет исходное внешнее событие с его глубокой персонализированной интерпретацией для бизнеса.

---

## Ключевые экраны и компоненты

### 1. Единая лента «Новость-Инсайт» (Smart Feed)
Главный экран приложения — это не абстрактный список заголовков, а лента готовых аналитических карточек, где новость неразрывно связана с бизнес-инсайтом:
- **Блок новости (Событие)**:
  - Заголовок, источник, дата публикации, отраслевой тег.
  - Верифицированная фактологическая сводка (что произошло, участники, сроки).
- **Блок инсайта (Персонализированная аналитика под клиента)**:
  - **Почему это важно для вашей компании**: сопоставление новости с ОКВЭД, долговой нагрузкой, импортом и цепочкой контрагентов.
  - **Риски и возможности**: емкие буллеты с оценкой финансового эффекта.
  - **Позиция Альфа-Банка**: официальная экспертная оценка с кликабельной ссылкой на PDF-отчет и номер страницы.
  - **Релевантное действие**: понятный следующий шаг для бизнеса + нативная интеграция продукта банка (гарантия, факторинг, кредит, депозит).
  - **Цветовая трассировка**: три строгих бейджа `[Факт]`, `[Позиция Банка]`, `[Вывод AI]`.
- **Интерактивные действия карточки**:
  - Кнопка *«Спросить нейросеть»* — открывает мини-чат по конкретной новости прямо в карточке.
  - Кнопка *«В закладки»* (добавить новость-инсайт в избранное).

### 2. Авторизация и контекст компании
- Экраны **Входа (Login)** и **Регистрации (Register)** с JWT-токенами.
- **Шапка с переключателем контекста**:
  - Выбор компании-клиента (переключение между демонстрационными профилями с выручкой > 15 млрд руб. и малым/средним бизнесом).
  - Выбор роли ЛПР (**CEO / Собственник**, **CFO / Казначей**, **Главный бухгалтер**).
  - При смене роли лента «Новость-Инсайт» мгновенно переранжируется и смещает акценты в карточках (CEO видит рынок и захват объемов, CFO — маржу и ставки, Главбух — налоги и штат).

### 3. Интерактивный диалог (Чат по новости)
- Возможность задать свободный вопрос внутри карточки («Что если наш поставщик поднимет цены на 10%?», «Есть ли альтернативы в нашем регионе?»).
- Стриминг ответа от AI-сервиса в реальном времени.

### 4. Личный кабинет (Закладки)
- Список сохраненных карточек «Новость-Инсайт».
- Фильтрация по статусу обработки и категориям.

---

## Рекомендуемый стек
- **Фреймворк**: React / Next.js / Vite + React
- **Стилизация**: Tailwind CSS (Bento Grid, темный/светлый корпоративный стиль)
- **Иконки**: Lucide Icons
- **Управление состоянием**: Zustand / React Context
- **Работа с API**: Axios / TanStack Query
