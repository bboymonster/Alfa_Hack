# 01. Frontend — Клиентская часть веб-приложения

## Зона ответственности
Разработка пользовательского интерфейса (UI/UX) для сайта новостей с инсайтами от нейросети и системой авторизации.

---

## Основной функционал

### 1. Авторизация и профиль пользователя
- Страницы **Входа (Login)** и **Регистрации (Register)**.
- Валидация форм (email, пароль, подтверждение пароля).
- Хранение токенов авторизации (JWT / LocalStorage / Cookie) и интерцепторы запросов.
- Личный кабинет / Профиль пользователя:
  - Отображение данных профиля.
  - Список сохраненных / избранных новостей (Bookmarks).
  - Выход из аккаунта (Logout).

### 2. Лента новостей и каталог
- Главная страница со списком актуальных новостей.
- Фильтрация по категориям (Финансы, Технологии, Бизнес, Рынки и т.д.).
- Поиск по ключевым словам.
- Пагинация или бесконечная прокрутка (infinite scroll).

### 3. Детальная страница новости и блок AI-инсайтов
- Полный текст новости, дата, автор/источник, теги.
- **Интерактивный блок «Инсайт от нейросети»**:
  - Краткая выжимка (TL;DR / Главная суть за 15 секунд).
  - Ключевые риски и возможности для бизнеса.
  - Тональность (позитивная / нейтральная / негативная) и уровень важности.
  - Интерактивная кнопка «Задать вопрос нейросети по этой новости» / генерация дополнительного инсайта.
- Кнопка добавления новости в «Избранное».

---

## Рекомендуемый стек
- **Фреймворк**: React / Next.js / Vite + React / Vue
- **Стилизация**: Tailwind CSS (быстрая и современная адаптивная верстка)
- **Иконки**: Lucide Icons
- **Управление состоянием**: Zustand / Redux Toolkit / React Context
- **Работа с API**: Axios / TanStack Query (React Query)

---

## Взаимодействие с командой
- **От Backend (`02-backend`)**: эндпоинты `/api/auth/register`, `/api/auth/login`, `/api/news`, `/api/news/{id}`.
- **От AI-модуля (`03-ai-service`)**: структура ответа с инсайтами (TL;DR, риски, возможности, скоринг).
- **От Infra (`04-infra-db`)**: конфигурация `.env` (URL бэкенда, порты).
